# Виджет банковских операций клиента

## Описание проекта
Проект представляет функции для обработки и отображения информации о банковских операциях клиента.

Основные задачи проекта:

- Определение типа номера (карта или счет) и соответствующая маскировка
- Преобразует строку с датой в формате "2024-03-11T02:26:18.671407" в строку формата "ДД.ММ.ГГГГ
- Фильтрация операций по статусу (`state`)
- Сортировка операций по дате

Функции проекта позволяют безопасно показывать клиенту его финансовые операции, скрывая персональные данные и предоставляя структурированный вывод.

## Функции проекта

### 1. `get_mask_card_number(card_number: str) -> str`
Маскирует номер банковской карты.

**Формат маскировки:**

XXXX XX** **** XXXX

- Видны первые 6 цифр  
- Видны последние 4 цифры  
- Всё между ними заменено на `*`

**Пример:**
```python
get_mask_card_number("4276123456781234")
# Результат: "4276 12** **** 1234"
```

### 2. `get_mask_account(account_number: str) -> str`

Маскирует номер банковского счёта.

**Формат маскировки:**

**XXXX

- Видны только последние 4 цифры
- Перед ними фиксированные **

**Пример:**
```python
get_mask_account("40817810099910004312")
# Результат: "**4312"
```

### 3. `mask_account_card(account_info: str) -> str`

Определяет тип номера (карта или счёт) и маскирует его соответствующей функцией.

Если в строке встречается слово "Счет" — применяется маскировка счёта.

В остальных случаях — маскировка карты.

**Пример:**
```python
mask_account_card("Visa Classic 4276123456781234")
# Результат: "Visa Classic 4276 12** **** 1234"

mask_account_card("Счет 40817810099910004312")
# Результат: "Счет **4312"
```
### 4. `get_date(date_str: str) -> str`
Преобразует строку с датой из формата ISO `"YYYY-MM-DDTHH:MM:SS.ssssss"` в привычный формат `"ДД.MM.ГГГГ"`.

**Пример:**
```python
get_date("2024-03-11T02:26:18.671407")
# Результат: "11.03.2024"
```

### 5. `filter_by_state(data: list, state: str = 'EXECUTED') -> list`

Фильтрует список операций (словарей) по значению поля state.

По умолчанию возвращает только операции со статусом EXECUTED.

**Пример:**
```python
operations = [
    {"id": 1, "state": "EXECUTED"},
    {"id": 2, "state": "CANCELED"}
]

filter_by_state(operations)
# Результат: [{"id": 1, "state": "EXECUTED"}]
```

### 6. `sort_by_date(data: list, reverse: bool = True) -> list`

Сортирует список операций по ключу date.

По умолчанию сортирует по убыванию (от новой операции к старой).

Если передать reverse=False — сортировка по возрастанию.

**Пример:**
```python
operations = [
    {"date": "2023-05-10T12:30:00"},
    {"date": "2023-03-01T10:00:00"}
]

sort_by_date(operations)
# Результат:
# [
#     {"date": "2023-05-10T12:30:00"},
#     {"date": "2023-03-01T10:00:00"}
# ]
```
## Новые функции модуля generators

### 1. `filter_by_currency` 
Фильтрует транзакции по коду валюты.

Принимает список словарей с транзакциями и возвращает генератор,
который поочередно выдаёт только те транзакции, у которых  
`operationAmount → currency → code` совпадает с указанным.

**Пример использования:**
```python
transactions_usd = list(filter_by_currency(transactions, "USD"))
```
### 2. `transaction_descriptions`  
Генератор, возвращающий описание (`description`) каждой транзакции.  
Проходит по списку транзакций и выдаёт только текст описания.

**Пример использования:**
```python
descriptions = transaction_descriptions(transactions)
next(descriptions)
```
### 3. `card_number_generator`  
Генератор номеров банковских карт в формате:  
`XXXX XXXX XXXX XXXX`  

Принимает начальное и конечное число диапазона,  
превращает каждое число в 16-значную строку с ведущими нулями
и форматирует её в вид номера карты.

**Пример использования:**
```python
for number in card_number_generator(1, 5):
    print(number)

Вывод:

0000 0000 0000 0001

0000 0000 0000 0002

0000 0000 0000 0003

0000 0000 0000 0004

0000 0000 0000 0005
```

## Использование фикстур

Фикстуры определяются в `tests/conftest.py` и используются для подготовки тестовых данных, чтобы не дублировать входные структуры.

Пример:

@pytest.fixture  
def sample_operations():  
    return [  
        {"id": 1, "state": "EXECUTED", "date": "2023-01-10T10:00:00"},  
        {"id": 2, "state": "CANCELED", "date": "2023-01-11T11:00:00"},  
    ]

## Покрытие тестами по модулям

### Модуль `masks.py`

Проверяется:

- корректная маскировка номеров карт  
- корректная маскировка номеров счетов  
- обработка некорректных входных данных  
- граничные случаи  

### Модуль `processing.py`

#### filter_by_state

Проверяется:

- фильтрация по умолчанию (`EXECUTED`)  
- фильтрация по разным значениям `state`  
- отсутствие элементов с указанным состоянием  
- работа с пустым списком  

#### sort_by_date

Проверяется:

- сортировка по убыванию дат  
- сортировка по возрастанию (`reverse=False`)  
- корректность при одинаковых датах  
- ошибки на неверных форматах дат  

### Модуль `widget.py`

Проверяется:

- преобразование ISO-дат в формат `ДД.ММ.ГГГГ`  
- работа с ISO-датами без времени  
- работа со строками, где отсутствует `T`  
- обработка пустых строк и `None`
