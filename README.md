# Виджет банковских операций клиента

## Описание проекта
Проект представляет функции для обработки и отображения информации о банковских операциях клиента.

Основные задачи проекта:

- Определение типа номера (карта или счет) и соответствующая маскировка
- Преобразует строку с датой в формате "2024-03-11T02:26:18.671407" в строку формата "ДД.ММ.ГГГГ
- Фильтрация операций по статусу (`state`)
- Сортировка операций по дате

Функции проекта позволяют безопасно показывать клиенту его финансовые операции, скрывая персональные данные и предоставляя структурированный вывод.

## Функции проекта

### 1. `get_mask_card_number(card_number: str) -> str`
Маскирует номер банковской карты.

**Формат маскировки:**

XXXX XX** **** XXXX

- Видны первые 6 цифр  
- Видны последние 4 цифры  
- Всё между ними заменено на `*`

**Пример:**
```python
get_mask_card_number("4276123456781234")
# Результат: "4276 12** **** 1234"
```

### 2. `get_mask_account(account_number: str) -> str`

Маскирует номер банковского счёта.

**Формат маскировки:**

**XXXX

- Видны только последние 4 цифры
- Перед ними фиксированные **

**Пример:**
```python
get_mask_account("40817810099910004312")
# Результат: "**4312"
```

### 3. `mask_account_card(account_info: str) -> str`

Определяет тип номера (карта или счёт) и маскирует его соответствующей функцией.

Если в строке встречается слово "Счет" — применяется маскировка счёта.

В остальных случаях — маскировка карты.

**Пример:**
```python
mask_account_card("Visa Classic 4276123456781234")
# Результат: "Visa Classic 4276 12** **** 1234"

mask_account_card("Счет 40817810099910004312")
# Результат: "Счет **4312"
```
### 4. `get_date(date_str: str) -> str`
Преобразует строку с датой из формата ISO `"YYYY-MM-DDTHH:MM:SS.ssssss"` в привычный формат `"ДД.MM.ГГГГ"`.

**Пример:**
```python
get_date("2024-03-11T02:26:18.671407")
# Результат: "11.03.2024"
```

### 5. `filter_by_state(data: list, state: str = 'EXECUTED') -> list`

Фильтрует список операций (словарей) по значению поля state.

По умолчанию возвращает только операции со статусом EXECUTED.

**Пример:**
```python
operations = [
    {"id": 1, "state": "EXECUTED"},
    {"id": 2, "state": "CANCELED"}
]

filter_by_state(operations)
# Результат: [{"id": 1, "state": "EXECUTED"}]
```

### 6. `sort_by_date(data: list, reverse: bool = True) -> list`

Сортирует список операций по ключу date.

По умолчанию сортирует по убыванию (от новой операции к старой).

Если передать reverse=False — сортировка по возрастанию.

**Пример:**
```python
operations = [
    {"date": "2023-05-10T12:30:00"},
    {"date": "2023-03-01T10:00:00"}
]

sort_by_date(operations)
# Результат:
# [
#     {"date": "2023-05-10T12:30:00"},
#     {"date": "2023-03-01T10:00:00"}
# ]
```

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/username/repository.git
cd repository
```
2. Дополнительные зависимости не требуются — используется только стандартная библиотека Python.

3. Импортируйте функции:
```python
from processing import (
    get_mask_card_number,
    get_mask_account,
    mask_account_card,
    filter_by_state,
    sort_by_date
)
```
